# Higgsfield UGC Storyboards - Paste-Ready Prompts

These are built for AI-video tools (Higgsfield, and works in Kling/Runway/Veo too). Each storyboard gives you, per shot:
- **IMAGE prompt** - to generate the keyframe (or use as image-to-video start frame)
- **MOTION prompt** - the camera/action instruction for the video gen
- **DIALOGUE / VO** - what's said or shown on screen
- **Text overlay** - burned-in caption

**Consistency tips for AI UGC**
- Lock ONE character: describe the same person every shot (age, hair, outfit, vibe). Reuse the same reference image/seed across shots so it's clearly the same creator.
- "UGC look" = shot on a phone, slightly imperfect, natural light, handheld, vertical 9:16, authentic, NOT cinematic/ad-like. Put that in every image prompt.
- Generate the product screen separately (real screen recording of `esim.mocaintel.com`) and cut it in - don't ask the AI to fake the UI, it'll look wrong and erode trust.
- Keep clips 3-5s each, then assemble 4-6 of them into one 15-25s video.

## Assembly checklist
1. Generate each character keyframe, lock the seed/reference so the person stays consistent.
2. Run image-to-video on each shot with the motion prompt (3-5s).
3. Record the REAL `esim.mocaintel.com` flow on your phone for the product shots - never AI-fake the UI.
4. Stitch in CapCut: hook first, product reveal in the middle, CTA last.
5. Add burned-in captions + a trending/royalty-free track.
6. Optional: run it through Higgsfield's virality predictor before posting, iterate the hook if the score is weak.
7. Export 9:16, native-upload to each platform (no cross-platform watermarks).

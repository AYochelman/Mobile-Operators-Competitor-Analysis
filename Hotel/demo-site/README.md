# MOCA Guest Connect — מיני-אתר הדגמה למלונות

אתר סטטי עצמאי לשיווק **MOCA Guest Connect** לרשתות מלונות, לפי `../Hotel Plan.txt`.
**ללא תלות במוצר הראשי** — אין React, אין build, אין Flask/Supabase. שני קבצי HTML בלבד.

## קבצים

| קובץ | מה זה |
|------|--------|
| `index.html` | דף הפיץ' (עברית, RTL) — hero, דמו חי בתוך מסגרת טלפון, איך זה עובד, מחשבון ROI אינטראקטיבי, דשבורד אנליטיקה לדוגמה, תמחור (Starter/Pro/Chain), FAQ, CTA לפיילוט |
| `guest.html` | פורטל האורח (מה שנפתח מסריקת ה-QR) — מובייל-first, אנגלית/עברית, אשף "מצא חבילה ב-10 שניות", Top picks מדורגים, רשימת כל החבילות עם סינון, הסבר eSIM. ממותג דינמית לפי `?brand=` |

## איך מריצים

- **מקומית**: פתיחה של `index.html` ישירות בדפדפן (עובד גם מ-file://), או:
  ```bash
  cd Hotel/demo-site
  python -m http.server 8788   # → http://localhost:8788
  ```
- **אירוח**: גרירת התיקייה `demo-site` ל-Netlify (או כל אחסון סטטי). כשהדף מתארח, ה-QR בדף הפיץ' מקודד אוטומטית את כתובת פורטל האורח — סריקה בפלאפון פותחת את הדמו, בדיוק כמו בפגישת מכירה.

## מיתוג (white-label demo)

פריסטים של רשתות מלונות פיקטיביות מוגדרים **בשני מקומות** — לשמור מסונכרן:

- `guest.html` → `const BRANDS = { pearl, bloom, verde, urban }` (שם, מונוגרמה, צבעים, רקע)
- `index.html` → `const BRAND_PRESETS = [...]` (תווית + swatch לכפתורי הבורר)

להוספת מותג לפגישה ספציפית: מוסיפים entry בשני הקבצים עם צבעי המלון של הלקוח — זה כל ה"דמו הממותג בדקות" מה-playbook (סעיף 6.3 בתוכנית).

פרמטרים לפורטל האורח: `guest.html?brand=pearl&lang=en|he`

## נתוני הדגמה

- החבילות ב-`guest.html` → `const DEALS` — מחירים מדגמיים (ספקים אמיתיים, מחירים להמחשה; מסומן disclaimer בשני הדפים). שער המרה קבוע `FX = 3.7`.
- מחשבון ה-ROI ב-`index.html` משתמש בהנחות התוכנית העסקית (סעיף 4.2): 15% סריקה, 20% המרה לרכישה, חלק מלון 50% מהעמלה.
- כפתור "Get this deal" לא מנווט החוצה — מציג toast שמדגים את מנגנון הייחוס (referral) למלון.
